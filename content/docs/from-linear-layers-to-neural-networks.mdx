线性模型用 `X @ W + b` 将输入映射为输出。扩展成多层神经网络后，训练仍然使用损失函数、反向传播和参数更新，主要变化在于前向函数：中间层构造特征，激活函数引入非线性。

在上一篇[从 Loss 到泛化](/docs/from-loss-to-generalization)的基础上，本文围绕五个问题展开：

- 一个线性层怎样同时产生多个输出？
- 多叠几层，为什么不一定增加表达能力？
- ReLU 没有参数，为什么会影响训练？
- Loss 还大于零，梯度为什么已经变成零？
- 单个样本的训练，怎样变成批量矩阵训练？

本文直接使用 PyTorch Tensor 实现一个两层网络：先标注前向计算的 shape，再用标量例子推导梯度，最后给出可运行的批量训练代码。参数创建、更新和梯度清零都显式写出，便于与后续的 `nn.Module` 和优化器对应。

## 符号与维度

本文用 $x,w$ 等普通斜体表示**标量**，用 $\mathbf{x},\mathbf{b}$ 等粗体小写表示**向量**，用 $\mathbf{X},\mathbf{W}$ 等粗体大写表示**矩阵**。$B$ 表示 batch 大小，$D$ 表示输入维度，$H$ 表示隐藏维度，$O$ 表示输出维度。

数学中的向量默认是列向量，数据矩阵的每一行对应一个样本。代码采用 `X @ W + b` 的权重布局，偏置通过广播加到每一行；公式会将广播显式写出。

## 线性层：同一份输入，计算多个加权组合

之前的线性模型只有一个输出：

$$
z=x_1w_1+x_2w_2+b=\mathbf{x}^{\mathsf T}\mathbf{w}+b
$$

如果希望两个输入特征产生三个输出，就为每个输出准备一组独立的权重和偏置：

$$
\begin{aligned}z_1&=x_1w_{11}+x_2w_{21}+b_1\\z_2&=x_1w_{12}+x_2w_{22}+b_2\\z_3&=x_1w_{13}+x_2w_{23}+b_3\end{aligned}
$$

把每组权重放在矩阵的一列：

$$
\mathbf{W}=\begin{bmatrix}w_{11}&w_{12}&w_{13}\\w_{21}&w_{22}&w_{23}\end{bmatrix}\in\mathbb{R}^{2\times3},\qquad
\mathbf{b}=\begin{bmatrix}b_1\\b_2\\b_3\end{bmatrix}\in\mathbb{R}^{3}
$$

对一批输入，三个输出可以同时计算：

$$
\mathbf{Z}=\mathbf{X}\mathbf{W}+\mathbf{1}_B\mathbf{b}^{\mathsf T}
$$

$\mathbf{1}_B$ 是长度为 $B$ 的全 1 向量，$\mathbf{1}_B\mathbf{b}^{\mathsf T}$ 将偏置重复到每一行。对应代码为：

```python
Z = X @ W + b
```

对应的 shape 是：

```text
X: [batch_size, 2]
W: [2, 3]
b: [3]
Z: [batch_size, 3]
```

这里每一行仍然对应一个样本。线性层改变的是每个样本的特征维度，样本数量没有变化。

例如：

```python
import torch

X = torch.tensor([[1.0, 2.0]])
W = torch.tensor([[1.0, 0.0, -1.0], [2.0, 1.0, 1.0]])
b = torch.tensor([0.0, 1.0, -1.0])

Z = X @ W + b
# tensor([[5., 3., 0.]])，shape 为 [1, 3]
```

这个线性层有 `2 * 3 + 3 = 9` 个参数。即使一次输入一百个样本，参数量也还是 9，因为所有样本共享同一组 `W` 和 `b`。

偏置通过广播加到每一行：`[3]` 对齐为 `[1, 3]`，再与 `[batch_size, 3]` 相加。这不会产生新的可训练参数。

严格来说，加上偏置的运算是仿射变换。深度学习里通常仍称它为线性层。本文使用 `W: [输入维度, 输出维度]` 的手写约定。

## 为什么多叠线性层仍然不够

先把两个线性层接起来：

$$
\begin{aligned}\mathbf{H}&=\mathbf{X}\mathbf{W}_1+\mathbf{1}_B\mathbf{b}_1^{\mathsf T}\\\mathbf{Y}&=\mathbf{H}\mathbf{W}_2+\mathbf{1}_B\mathbf{b}_2^{\mathsf T}\end{aligned}
$$

假设输入、隐藏特征和输出分别是：

```text
X:  [4, 2]
W1: [2, 3]    b1: [3]
H:  [4, 3]
W2: [3, 1]    b2: [1]
Y:  [4, 1]
```

代入并展开第二个式子：

$$
\begin{aligned}\mathbf{Y}&=(\mathbf{X}\mathbf{W}_1+\mathbf{1}_B\mathbf{b}_1^{\mathsf T})\mathbf{W}_2+\mathbf{1}_B\mathbf{b}_2^{\mathsf T}\\&=\mathbf{X}(\mathbf{W}_1\mathbf{W}_2)+\mathbf{1}_B(\mathbf{b}_1^{\mathsf T}\mathbf{W}_2+\mathbf{b}_2^{\mathsf T})\end{aligned}
$$

于是可以定义：

```python
W_merged = W1 @ W2       # [2, 1]
b_merged = b1 @ W2 + b2  # [1]
Y = X @ W_merged + b_merged
```

第一层的偏置也经过了第二层的权重变换，所以合并偏置不是简单地把两个偏置相加。

合并后的参数不依赖具体输入，意味着两种写法对任意兼容输入都等价。继续叠加第三层，也可以用同样的方法合并。

> **只叠加线性层，最终仍然只能表达一个仿射变换。** 增加层数本身不能引入非线性。

这说的是可表达的函数形式。不同分解方式仍可能影响优化过程，隐藏维度还可能限制等效权重的秩，但这些都不会把纯线性层组合变成非线性函数。

## ReLU：不增加参数，却改变函数形式

ReLU 的规则只有一条：

$$
\operatorname{ReLU}(z)=\max(0,z)
$$

它逐元素把负数变成零，非负数保持不变：

$$
\operatorname{ReLU}\!\left(\begin{bmatrix}-2\\0\\3\end{bmatrix}\right)=\begin{bmatrix}0\\0\\3\end{bmatrix}
$$

为什么它不能用同一个 `w * x + b` 表示？如果匹配 `x=0` 和 `x=1` 的 ReLU 输出，就必须有 `b=0`、`w=1`。此时输入 `x=-1`，线性模型输出 -1，ReLU 却输出 0。

把 ReLU 放到两层之间：

```python
H = X @ W1 + b1  # [batch_size, 3]
A = torch.relu(H)  # [batch_size, 3]
Y = A @ W2 + b2  # [batch_size, 1]
```

写成矩阵形式为：

$$
\begin{aligned}
\mathbf{H}&=\mathbf{X}\mathbf{W}_1+\mathbf{1}_B\mathbf{b}_1^{\mathsf T}\\
\mathbf{A}&=\operatorname{ReLU}(\mathbf{H})\\
\hat{\mathbf{Y}}&=\mathbf{A}\mathbf{W}_2+\mathbf{1}_B\mathbf{b}_2^{\mathsf T}
\end{aligned}
$$

其中 ReLU **逐元素作用于矩阵**。shape 没变，但中间特征的值可能改变。比如某个样本的 `H` 是 `[5, 2, -3]`，激活后就是 `[5, 2, 0]`。

若第二层权重向量为 $\mathbf{w}_2=[2,-1,1]^{\mathsf T}$，偏置为 $0.5$：

$$
\begin{aligned}\hat{y}_{\text{无激活}}&=5\times2-2-3+0.5=5.5\\\hat{y}_{\text{ReLU}}&=5\times2-2+0+0.5=8.5\end{aligned}
$$

ReLU 没有可训练参数，改变的是不同输入下参与后续计算的特征。网络一般不能再按之前的公式合并成一个线性层。不过，特定参数或限定输入范围下仍可能退化为线性关系；加了 ReLU 并不保证所有情况下都会表现出非线性。

## 梯度怎样穿过 ReLU

为了把求导过程看清楚，先缩成没有偏置、只有一个隐藏单元的网络。所有变量都是标量，shape 为 `[]`：

$$
\begin{aligned}h&=xw_1,\qquad a=\operatorname{ReLU}(h)\\\hat{y}&=aw_2\\\ell&=\frac12(\hat{y}-y)^2\end{aligned}
$$

前面的 0.5 用于抵消平方求导产生的系数 2。这里的 Loss 是一半的平方误差，和直接使用 MSE 的数值相差一倍。

ReLU 的局部导数可以直接从函数规则理解：

- `h > 0` 时，输出等于输入，输入增加一点，输出增加同样多，导数是 1。
- `h < 0` 时，只要变化后仍为负数，输出一直是零，导数是 0。
- `h = 0` 时，左右斜率不同，数学上不可导；PyTorch 的 ReLU 反向传播在这里使用 0。

`w1` 影响 Loss 的路径是：

$$
w_1\longrightarrow h\longrightarrow a\longrightarrow\hat{y}\longrightarrow\ell
$$

链式法则要求沿途的局部导数相乘：

$$
\frac{\partial\ell}{\partial w_1}=\frac{\partial\ell}{\partial\hat{y}}\frac{\partial\hat{y}}{\partial a}\frac{\partial a}{\partial h}\frac{\partial h}{\partial w_1}
$$

逐项看：

$$
\begin{aligned}\frac{\partial\ell}{\partial\hat{y}}&=\hat{y}-y,&\frac{\partial\hat{y}}{\partial a}&=w_2\\\frac{\partial a}{\partial h}&=\mathbf{1}_{h>0},&\frac{\partial h}{\partial w_1}&=x\end{aligned}
$$

$\mathbf{1}_{h>0}$ 是**指示函数**：条件成立取 1，否则取 0；这里得到的是标量，不是全 1 向量。$\hat{y}$ 和 $y$ 分别对应代码中的 `prediction` 和 `target`。

因此手算梯度可以写为：

```python
dloss_dprediction = prediction - target
da_dh = (h > 0).float()

manual_dw2 = dloss_dprediction * a
manual_dw1 = dloss_dprediction * w2 * da_dh * x
```

最后的 $x$ 来自 $\partial h/\partial w_1$，不能省略。若只计算前三项，得到的是 $\partial\ell/\partial h$；继续乘以 $x$，才得到需要用于更新 $w_1$ 的梯度。

当 `x=2`、`w1=1`、`w2=3`、目标为 1 时：

$$
\begin{aligned}h&=2,\quad a=2,\quad\hat{y}=6\\\frac{\partial\ell}{\partial w_2}&=(6-1)\times2=10\\\frac{\partial\ell}{\partial w_1}&=(6-1)\times3\times1\times2=30\end{aligned}
$$

这两个手算结果可以用来核对 `loss.backward()` 得到的 `w1.grad` 和 `w2.grad`。Autograd 沿计算图执行链式法则并写入梯度，参数更新是之后的独立步骤。

## detach 和 no_grad 各自负责什么

核对手算梯度时，只需要比较数值，不需要为核对过程再构建一张计算图。`detach()` 可以将某个 Tensor 从当前求导关系中分离出来。

在上面的手算公式中，不使用它也能得到正确数值。只是因为 `prediction` 等 Tensor 带有求导关系，PyTorch 还会记录手算部分的运算，而这次并不需要继续对手算梯度求导。

```python
dloss_dprediction = prediction.detach() - target
```

这里 `detach()` 返回数值相同、与原计算图断开的 Tensor，不修改原来的 `prediction`。如果希望整个手算部分都不建立计算图，其他参与计算的带梯度 Tensor 也需要相应处理，或者把手算部分放进 `torch.no_grad()` 中。

`detach()` 不复制数据，它与原 Tensor 共享存储。因此不能把它理解为一份独立备份。

`no_grad()` 则控制一段运算是否被记录。手动更新参数时使用：

```python
with torch.no_grad():
    w1 -= learning_rate * w1.grad
    w2 -= learning_rate * w2.grad
```

这不取消参数本身的 `requires_grad=True`。退出上下文后，下一轮前向计算仍会建立计算图。

## 学习率更大，第一步更好，却可能无法继续学习

用刚才的参数做一次更新，学习率取 0.01：

$$
\begin{aligned}w_1^{\mathrm{new}}&=1-0.01\times30=0.7\\w_2^{\mathrm{new}}&=3-0.01\times10=2.9\end{aligned}
$$

重新计算预测和 Loss：

$$
\begin{aligned}\hat{y}&=\operatorname{ReLU}(2\times0.7)\times2.9=4.06\\\ell&=\tfrac12(4.06-1)^2=4.6818\end{aligned}
$$

相比更新前的 12.5，Loss 下降了。接着把这个过程重复 100 次，并让两个学习率都从相同参数开始，得到：

| 学习率 | 第一次更新后 Loss | 第 100 次更新后 Loss | 最终预测 |
| --- | --- | --- | --- |
| 0.01 | 4.6818 | 接近 0 | 接近 1 |
| 0.1 | 0.5 | 0.5 | 0 |

较大的学习率第一步反而更好，但随后停住了。原因是第一次更新就把 `w1` 变成了 -2：

$$
h=2\times(-2)=-4,\qquad a=\operatorname{ReLU}(-4)=0
$$

于是：

- **$w_1$ 的梯度为零**：链式法则中乘上了 ReLU 的零导数。
- **$w_2$ 的梯度也为零**：$\partial\hat{y}/\partial w_2=a$，而此时 $a=0$。

参数不再变化，同一个输入产生的 `h` 就一直为负。再训练一千步也无法离开这个状态。

这是 ReLU 神经元失活的一种具体情形。不过，某个样本激活为零，不代表神经元永久失活；其他样本可能产生正的激活并提供梯度。本实验只有一个固定样本、一个隐藏单元，而且没有偏置。

这次实验说明了两件事：一次 Loss 下降不保证后续训练顺利；梯度为零也不一定代表模型已经学好。

## 从单个样本扩展到批量：先检查 Loss 的 shape

批量训练时，参数仍然共享。四个样本产生四个预测值：

```text
X:           [4, 2]
H、A:        [4, 3]
predictions: [4, 1]
targets:     [4, 1]
```

每个样本先计算自己的损失，再平均：

```python
per_sample_loss = 0.5 * (predictions - targets) ** 2  # [4, 1]
loss = per_sample_loss.mean()  # []
loss.backward()
```

对应的是：

$$
L=\frac14\sum_{i=1}^{4}\ell_i=\frac14\sum_{i=1}^{4}\frac12(\hat{y}_i-y_i)^2
$$

每个参数的梯度也是各样本损失梯度的平均。它已经汇总了样本贡献，因此**梯度 shape 与参数一致，不额外保留 batch 维度**：

| 参数 | 参数 shape | 梯度 shape |
| --- | --- | --- |
| W1 | [2, 3] | [2, 3] |
| b1 | [3] | [3] |
| W2 | [3, 1] | [3, 1] |
| b2 | [1] | [1] |

例如，输出偏置加到每个样本的预测上，预测对偏置的导数都是 1。所以在这个损失定义下：

$$
\frac{\partial L}{\partial b_2}=\frac{1}{B}\sum_{i=1}^{B}(\hat{y}_i-y_i)
$$

以下方完整代码的初始参数为例，四个预测误差是 `[6.5, 6.5, 0.5, 0.5]`，平均为 3.5，因此第一次反向传播应得到 `b2.grad = 3.5`。

这里最隐蔽的错误是把目标写成 `[4]`：

```text
predictions: [4, 1]
targets:        [4] → 对齐为 [1, 4]
相减结果:    [4, 4]
```

结果的第 i 行、第 j 列成了 `prediction_i - target_j`，即每个预测都和所有目标相减。程序仍然可以求平均、反向传播，却已经在优化错误的目标。

**广播成功不等于计算正确。** 本例在计算损失前直接检查：

```python
assert predictions.shape == targets.shape
```

## 一个可以直接运行的批量训练循环

下面是最终实验的完整代码。它使用四个二维样本、三个隐藏单元和一个回归输出，每轮都用全部样本训练，因此这里一个 epoch 对应一次参数更新。

```python
import torch

X = torch.tensor([[1.0, 2.0], [3.0, 1.0], [-1.0, 0.0], [0.0, -2.0]])  # [4, 2]
targets = torch.tensor([[1.0], [2.0], [-1.0], [0.0]])  # [4, 1]

W1 = torch.tensor([[1.0, 0.0, -1.0], [2.0, 1.0, 1.0]], requires_grad=True)  # [2, 3]
b1 = torch.tensor([0.0, 1.0, -1.0], requires_grad=True)  # [3]
W2 = torch.tensor([[2.0], [-1.0], [1.0]], requires_grad=True)  # [3, 1]
b2 = torch.tensor([0.5], requires_grad=True)  # [1]

parameters = [W1, b1, W2, b2]
learning_rate = 0.01

for epoch in range(1, 301):
    H = X @ W1 + b1  # [4, 3]
    A = torch.relu(H)  # [4, 3]
    predictions = A @ W2 + b2  # [4, 1]
    assert predictions.shape == targets.shape
    loss = (0.5 * (predictions - targets) ** 2).mean()  # []

    loss.backward()

    with torch.no_grad():
        for parameter in parameters:
            parameter -= learning_rate * parameter.grad

    for parameter in parameters:
        parameter.grad.zero_()

    with torch.no_grad():
        updated_predictions = torch.relu(X @ W1 + b1) @ W2 + b2
        updated_loss = (0.5 * (updated_predictions - targets) ** 2).mean()

    if epoch == 1 or epoch % 50 == 0:
        print(f"epoch={epoch:3d}  train_loss={updated_loss.item():.6f}")

print(updated_predictions)
```

有几个容易被简短代码掩盖的细节：

1. **每轮重新前向计算。** 参数已经变化，旧的预测和 Loss 不会自动刷新。
2. **一次 backward 计算四组参数的梯度。** 它们都通过本轮计算图影响同一个 Loss。
3. **参数依次更新，但使用的是同一次 backward 得到的梯度。** 更新 `W1` 后，不会自动重算 `W2.grad`。
4. **`-=` 原地修改参数。** 在这个循环里写 `parameter = parameter - ...`，只会改变局部变量的指向，不会更新原来的 `W1` 等对象。
5. **梯度使用后清零。** `.grad` 默认累加；也可以在下一轮 backward 前清零，关键是不要意外累积旧梯度。
6. **更新后的评价不需要计算图。** 这里只观察 Loss，用 `no_grad()` 即可。

## 实验结果：训练误差与泛化能力

实际运行 300 轮后：

```text
epoch=  1  train_loss=4.734133
epoch= 50  train_loss=0.016504
epoch=100  train_loss=0.011421
epoch=150  train_loss=0.009378
epoch=200  train_loss=0.007790
epoch=250  train_loss=0.006481
epoch=300  train_loss=0.005396
```

这里打印的全部是每轮更新后的 Loss。初始化时的 Loss 为 10.625。

| 目标值 | 最终预测 |
| --- | --- |
| 1 | 1.0113 |
| 2 | 1.9886 |
| -1 | -1.0515 |
| 0 | 0.2006 |

网络已经较好地拟合这四个训练样本，但还没有完全拟合，尤其第四个样本仍有明显误差。**本实验没有验证集和测试集，不能据此说明泛化能力。**

这个实验的价值是把训练的每一环都实际执行了一遍：矩阵参数产生预测，标量 Loss 汇总样本误差，反向传播计算共享参数的梯度，再用这些梯度修改参数。

## 手写网络中的三个检查点

| 检查点 | 需要确认的内容 |
| --- | --- |
| 前向计算 | 矩阵维度兼容，激活函数位置正确，预测与目标 shape 一致 |
| 反向传播 | Loss 为标量，参数连接到计算图，梯度 shape 与参数一致 |
| 参数更新 | 使用本轮梯度更新原参数，清除旧梯度，下一轮重新前向计算 |

Loss 不下降时，可以沿这三个位置逐步检查。尤其要区分“梯度已正确计算”和“参数确实得到更新”，以及“梯度为零”和“误差已经足够小”。
